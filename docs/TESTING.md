## 首次使用与授权

- [ ] 新安装默认不能接受远程控制；未配对设备不能启动会话或注入输入。
- [ ] 两端连接相同 WSS 服务；邀请来自目标电脑；核对完整指纹后才批准。
- [ ] 关闭配对模式、超过有效期、错误邀请、错误服务地址均不能意外完成配对。
- [ ] 拒绝 macOS 屏幕录制或辅助功能权限后，界面显示问题；补齐权限并重启后能够工作。
- [ ] 关闭设备控制权限或解除配对后，对方不能继续控制；已建立的被控会话停止。
- [ ] 用系统剪贴板粘贴分组及连续的 8 位配对码，核对前导零。关闭配对码后确认无法再复制，过期代码不能配对。
- [ ] 控制端断开连接服务时，设备统一显示「状态未知」。恢复服务后，等待设备状态更新，再分别核对在线与离线设备。
- [ ] 两台电脑分别退出并重开，已保存配对仍有效；密钥文件无法解密时不静默生成新身份。

## 双向画面与输入

以下项目必须在两个方向各做一次：

- [ ] 文档、小字号表格、代码编辑器与快速滚动内容可辨认，持续更新。
- [ ] 鼠标四角定位、单击、双击、右键、中键、拖拽和滚轮正常。
- [ ] 字母、数字、方向键、删除键、功能键及 Ctrl/Shift/Alt/Command/Windows 组合键符合远端系统行为。
- [ ] 使用本机输入法直接输入中文、标点与表情，确认只写入远端当前焦点，没有自动同步剪贴板。
- [ ] 松开按键、切换窗口、鼠标离开画面、断开连接后，没有残留按下的按键或鼠标按钮。
- [ ] 对方按住 Shift 或拖拽时，机主开启「仅允许观看」。确认按键与拖拽释放，视频继续，对方点击和打字不会生效。恢复权限后由控制端重新开启键鼠。使用旧版控制端时，通过重新连接恢复操作。
- [ ] Retina、Windows 100%/150%/200% DPI、左右/上下副屏和负坐标显示器分别验证定位。
- [ ] 每次只共享选定显示器；插拔被控显示器后安全停止或明确报错，不把输入发送到另一块未选定的屏幕。
- [ ] 分别测试三档画质；记录实际结果，确认低带宽时没有不断增加的画面延迟。

帧率可能随屏幕变化量降低，静态桌面下较低帧率不一定意味着异常。网络 RTT 只表示网络往返时间，不等于鼠标操作到画面反馈的完整延迟。需要端到端延迟时，用外部摄像机同时记录操作与画面变化，单独报告该测量值。

## 公司 / 家庭网络

- [ ] 在实际公司和家庭网络之间连接，记录候选路径；成功连接协调服务并不等于视频已连通。
- [ ] 用有效 TURN 凭据开启“仅中继”设置验证 TURN 路径；测试完恢复自动选择。
- [ ] 分别验证 TURN/UDP、TURN/TCP；配置了可信证书时验证 TURN/TLS。
- [ ] 错误 TURN 密码应连接失败或仅通过可用直连成功，不应偷偷使用公共中继。
- [ ] 模拟断网、Wi-Fi 切换、协调服务重启，检查状态提示、按键释放和重新连接。
- [ ] 有认证门户、代理或只允许 TCP 443 的网络分别检查；无法穿越时清楚记录限制，不把服务部署错误当作客户端性能问题。

公司网络限制应在获准的测试条件下检查。测试不需要关闭操作系统安全功能；UAC 安全桌面和锁屏界面属于当前不支持的范围。

## 无人值守与长时间会话

- [ ] 应用保持运行、桌面已登录且未锁定时，从已配对设备建立无人值守连接。
- [ ] 应用退出后不能继续连接；打包版开启登录后启动后，用户重新登录会启动应用。
- [ ] 本地断开按钮和紧急快捷键有效；系统占用快捷键时本地按钮仍可使用。
- [ ] 连续使用至少 60 分钟，记录断线次数、CPU/内存变化、画面是否停滞、输入是否延迟积累。
- [ ] 进行至少 20 次连接/断开，检查视频轨道、输入辅助进程、网络连接和按键状态是否正确清理。
- [ ] 测试睡眠、锁屏、唤醒、注销后的实际行为，并记录需要用户恢复的步骤；不把登录后启动理解为登录前访问能力。
