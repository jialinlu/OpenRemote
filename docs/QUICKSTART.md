# OpenRemote 使用说明

## 打开对方的命令行

两台电脑均使用 0.3.5 或更高版本，先完成下方的设备配对。机主开启「允许远程访问」并允许这台配对设备控制本机。控制方在设备行点击「远程终端」，机主核对设备编号，在弹窗中选择「允许本次终端」。超过 30 秒仍未确认，控制方可以重新申请。

机主看到的是本机 zsh（Mac）或 Windows PowerShell；控制方看到同一窗口。机主将该终端保持在前台，控制方点进画面即可输入或粘贴命令。机主可在共享提示窗中勾选「仅允许观看」，也可关闭终端结束会话。选择「结束并暂停远程访问」还会关闭本机的访问开关。

## 用系统 SSH 登录

打开设备页右上角的「SSH 终端」，或者展开已配对设备的详情并选择 SSH 入口。输入可达的 SSH 地址和端口，用户名留空时使用系统 SSH 的默认用户。首次登录请与主机管理员核对指纹，在系统终端中输入密码或密钥口令。成功打开终端后，应用会在本机加密存储中记住地址、端口和用户名。

没有运行 OpenRemote 的 SSH 服务器也可以使用此入口。若终端提示超时，请检查地址、端口和当前网络或 VPN；提示拒绝连接时，请确认目标的 SSH 服务已在该端口运行。出现主机密钥变更提示时，请先联系管理员核对。SSH 会话由系统终端管理，输入 `exit` 即可结束。

## 配对与桌面共享

请阅读 [0.3.0 新操作方式与升级说明](OPENREMOTE-0.3.0.md)。

两端安装新版，退出旧版后台进程后启动。原设备数据保留，已配对设备通常可直接连接。macOS 首次运行新版可能要求允许访问旧的 `bridgedesk Safe Storage` 钥匙串，这是读取既有设备身份所需的系统授权。由你本人在系统弹窗中完成确认；不要把密码发到聊天或写进文件。

首次配对时，一台启动连接服务、导出连接文件并生成配对码；另一台导入文件并输入 8 位数字；被请求方确认设备。配对码五分钟有效，连续五次错误关闭本轮配对。

在 macOS 上共享整个桌面需要录屏和辅助功能权限。如果已开启但仍未就绪，可在系统设置中移除旧应用权限条目，再添加当前安装的 OpenRemote.app 并开启权限，然后退出重开。新系统可能将辅助功能权限页面称为“设备控制和数据访问”。

控制端点击设备的“连接桌面”，在独立窗口中直接操作。中文使用本机输入法，选字后提交到远端。按 Shift + Esc 可释放远端键鼠并返回本地工具栏，勾选“键鼠控制”后即可继续输入。关闭远控窗口结束连接。

被控端的共享提示窗显示访问设备。“结束本次共享”保留后续访问权限，“结束并暂停远程访问”同时关闭本机的远程访问开关。关闭控制台后，应用会继续在菜单栏或托盘运行。

临时入口重启可能换地址。需要时导出最新连接文件，在已配对的另一台导入即可更新地址，保留原授权。被控设备需保持已登录、未锁屏、应用运行。
