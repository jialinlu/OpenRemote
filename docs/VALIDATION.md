# OpenRemote 验证记录

## 0.3.5 · 2026-11-24

- 语法检查、130 项基础测试、Chrome 渲染测试和隔离 Electron 桌面测试通过。
- 在 macOS 上用两个隔离 Electron 实例和本机信令服务配对。控制方从设备行申请终端后，真实的 WebRTC 视频、键盘事件和本机 zsh 完成了中文命令回显测试。机主将其他窗口切到前台后终端停止接收远端输入。机主收回输入后画面保留，关闭终端后双方会话结束。集成测试以临时设备身份模拟机主点击确认。
- 用两个颜色不同且互相遮挡的窗口验证了对应标签页的视频源。控制方收到的是指定窗口的像素。终端会话没有枚举显示器或调用全局键鼠助手。
- 自动化测试覆盖拒绝、审批超时、取消后到达的旧确认、撤销设备权限、仅观看及输入权限修订、窗口调用隔离和终端组件退出。Chrome 回归还覆盖了非文本和超长粘贴、终端信令与桌面兼容性、900 像素宽窗口的入口布局。
- 真实 macOS 窗口已验证本机 PTY 及 Ctrl+C。Windows x64 包使用 ConPTY 和 Windows PowerShell，Windows 实机交互及跨网两机连接仍待验证。

## 0.3.4 · 2026-11-24

- JavaScript 语法检查、117 项基础测试、Chrome 合成画面渲染测试及隔离 Electron 桌面测试通过。
- 在设备尚未配对、本机信令服务离线及设备专属入口等场景验证了 SSH 对话框、键盘提交、错误重试和焦点恢复。SSH 设置仅供本机控制台访问，桌面会话快照和共享提示窗均不包含这些设置。
- macOS 系统 OpenSSH 在隔离的本地 SSH 服务上，以模块生成的参数在非默认端口完成公钥认证、分配终端并交换文本。更换主机密钥后客户端拒绝登录。测试使用临时密钥、专用 known_hosts 和只回显文字的测试服务。
- macOS 启动测试检查了交付给 Terminal.app 的临时文件和清理流程；Windows 测试检查了 OpenSSH 与系统终端的启动参数和客户端缺失提示。本轮没有在用户实际终端或 Windows 设备上进行端到端登录。

## 0.3.3 · 2026-11-24

- JavaScript 语法检查和 109 项基础测试通过。
- Chrome 验证了带空格的 8 位配对码、前导零、连续数字、超长输入及到期后隐藏复制按钮。主进程测试用内存剪贴板验证了有效期、复制结果及窗口权限。
- 本机断线时，多台设备均显示「状态未知」，故障提示只出现一次。服务恢复后，在设备状态返回前仍显示未知，明确离线的设备才给出离线提示。
- 在两端 Chrome 的合成 WebRTC 会话中，从被控端开启「仅允许观看」后，控制端禁用键鼠，视频持续解码。在 ICE 重连后，画面继续播放且限制保持。机主恢复权限、控制端开启键鼠后可继续输入。
- 主进程回归覆盖已按住按键的释放、旧输入丢弃、旧版控制端兼容与新会话的权限重置。隔离 Electron 45.2.3 验证了配对和会话窗口的生命周期，并确认控制台和远端会话窗均无权更改被控端的共享权限。
- Mac ARM64 DMG 已通过磁盘映像、深度签名和 ASAR 完整性检查。Windows x64 的应用源码、版本资源与 ASAR 已核对。真实系统键鼠、Windows 实机及跨网两机操作仍待按[两机验收清单](TESTING.md)验证。

## 0.3.2 · 2026-11-24

- JavaScript 语法检查和 104 项基础测试通过。
- 在 1240 × 850 的控制台展示两台在线、一台离线的合成设备。在 900 × 650 窗口使用长中文设备名，连接按钮仍完整可见，状态紧邻按钮，离线设备按钮禁用。空格与回车可展开、收起权限详情，数据刷新保留键盘焦点。
- 隔离 Chrome 验证了合成 WebRTC 画面、键鼠控制切换、断线重连及共享提示窗的两个操作。隔离 Electron 45.2.3 验证了设备配对、独立会话窗口、会话结束及原因反馈。
- Mac ARM64 DMG 通过磁盘映像、应用深度签名和 Electron ASAR 完整性校验。Windows x64 安装器、便携 ZIP 分别解包核验了版本与 ASAR。三个成品中的应用源码、17 个 Fluent 图标和两份 Fluent 许可证均已与工作区核对。
- Windows 实机、真实屏幕采集和跨网两机操作仍待按[两机验收清单](TESTING.md)验证。

## 0.3.1 · 2026-11-24

## 0.3.0

- 基础测试：98 项通过，包含配对码格式、过期、错误次数关闭窗口。
- JavaScript 语法检查通过。
- 隔离 Chrome 合成画面：真实 WebRTC 编解码与输入数据通道通过；直接 Unicode 输入、中文组合事件只提交一次、快捷键、连续按键、只读模式、失焦释放、单光标样式、ICE 恢复与断开后停止输入通过。
- 隔离 Electron 源码运行：真实独立 BrowserWindow、关闭会话窗口后保留控制台、IPC 角色隔离、8 位码配对、连接文件导入导出、菜单移除通过。
- 临时测试身份：0.2.0 加密身份由 0.3.0 延续，身份未变。
- Mac ARM64 DMG/ZIP 和 Windows x64 安装器/ZIP 已构建，Mac ad-hoc 签名深度校验通过；两端包内源码/许可证与当前源码一致，ZIP 完整性校验通过。

打包版自动启动检查遇到 macOS 钥匙串授权弹窗后超时；没有绕过系统授权，不能将源码集成检查等同于打包版完整运行验收。首次安装运行新版需使用者完成系统提示。

本轮没有重新操作用户真实桌面或注入系统输入，未验证真实 Windows 运行、各平台真实输入法候选窗行为及跨网长期质量。中文事件检查使用合成组合事件，不等同于所有系统输入法实测。真实验收清单见 TESTING.md。

公开包不包含设备身份、配对码、地址、桌面画面或原始会话记录。
