# 0.3.3 公开源码范围

公开源码以 0.3.3 源码归档为基准。首次提交前，对归档内的 104 个文件与对应开发源码逐字节核对，并检查了个人目录、设备身份、私钥、常见令牌、邀请和运行数据。部署配置中的域名及凭据由部署者填写，测试中使用合成数据或临时生成的身份。

仓库另行整理了使用说明、构建说明及构建配置。README 的截图来自隔离的合成界面测试。`SHA256SUMS` 覆盖当前提交中的源文件、文档及截图，清单自身除外。运行环境、依赖缓存、安装包和设备身份存储均由本地构建或使用时生成。

以上记录针对本次源码整理。第三方来源与许可见[组件说明](THIRD-PARTY.md)，应用行为的验证范围见[测试记录](VALIDATION.md)。
